# 🛡️ 钢铁前线 Steel Front · 2D 坦克大战

[![在线试玩](https://img.shields.io/badge/🎮_在线试玩-GitHub_Pages-ffb52e?style=for-the-badge&logo=github)](https://caiqing.github.io/tank-battle/)

**▶ 立即开战：<https://caiqing.github.io/tank-battle/>**

纯前端 Canvas 实现的上帝视角（俯视全图）2D 坦克对战游戏，无任何构建依赖，打开即玩。支持桌面键鼠与手机/平板触屏双摇杆。

## 🚀 运行方式

任选其一：

- **在线游玩**（GitHub Pages，无需安装）：**<https://caiqing.github.io/tank-battle/>**
- **直接打开**：下载本仓库后双击 `index.html`（推荐用 Chrome / Edge / Safari 最新版）
- **本地服务器**：

  ```bash
  cd tank-battle
  python3 -m http.server 8741
  # 浏览器访问 http://127.0.0.1:8741
  ```

## 🎮 游戏模式

主菜单提供两种战斗模式 + 武器商店：

| 模式 | 玩法 |
|------|------|
| ⚔️ **1v1 决斗** | 单车对决，击败敌方指挥车即胜（+300 分）。历史胜场越多，敌方战车越强，第 3 胜后敌方派出重装坦克 |
| 🌊 **1v多 生存** | 抵御无穷波次敌军（侦察车 / 主战坦克 / 重装坦克），清波获得递增奖励并自动战地维修 +15 HP，战损即结算。**每 5 波遭遇「指挥重坦」Boss**（三连扇形弹幕、头顶常显血条、击毁 +300 分并必掉双份补给） |
| 🛒 **武器商店** | 消耗战斗积分购买炮弹、防护装备、攻击武器 |

## 🕹️ 操作

| 按键 | 功能 |
|------|------|
| `W A S D` / 方向键 | 驾驶坦克 |
| 鼠标移动 | 炮塔瞄准 |
| 鼠标左键 | 主炮射击 |
| 右键 / `Shift`（按住） | 并联机枪（需先购买弹药） |
| `1` ~ `5` | 切换弹种（标准弹无限，特殊弹消耗库存） |
| `T` | 切换 🤖 **AI 托管**（自动走位/躲弹/预判开火/选弹/维修，可纯观战） |
| `H` | 使用战地维修包 |
| `P` / `Esc` | 暂停（结算界面 `Esc` 返回主菜单） |

## 📱 触屏操作（手机 / 平板）

首次触摸屏幕自动切换为触控模式（虚拟双摇杆）：

| 触控 | 功能 |
|------|------|
| 左半屏拖动 | 虚拟摇杆驾驶坦克（触点即摇杆中心） |
| 右半屏拖动 | 虚拟摇杆瞄准，**推出死区即自动开火** |
| 🔫 按钮（按住） | 并联机枪 |
| 🔧 按钮 / HUD 维修条 | 使用战地维修包 |
| 🤖 按钮 | 切换 AI 托管 |
| 点击弹种栏 | 切换炮弹 |

- 建议横屏游玩，竖屏时战斗画面会显示旋转提示
- 触屏设备自动降低粒子特效密度以保证流畅

## 🎱 炮弹弹射与溅射

- **标准弹**与**穿甲弹**（含敌方同型弹药）碰墙会**镜面反弹一次**，反弹后的炮弹带白色描边
- 弹着点产生小范围**溅射伤害**（直射伤害的 30%，不伤发射方），并对砖墙造成半额损伤
- 躲在墙后不再绝对安全——双方都可以用**跳弹**攻击拐角后的目标

## 🛒 商店货架

**💣 炮弹（消耗品）**

- **穿甲弹 AP**（200 分/10 发）：单发 62 高伤，一炮拆砖墙
- **高爆弹 HE**（250 分/8 发）：范围爆炸，拆墙与清场
- **榴霰弹 SG**（220 分/8 发）：一次扇面齐射 5 枚弹丸
- **追踪导弹 MS**（400 分/5 枚）：自动锁定最近的敌车

**🔫 攻击武器**

- **并联机枪弹药**（150 分/200 发，首次购买自动装配机枪）
- **炮管强化**（永久，5 级）：主炮伤害 +12%/级
- **自动装弹机**（永久，4 级）：主炮冷却 -9%/级

**🛡️ 防护装备**

- **能量护盾电池**（150 分/个，每场最多装载 3 个）：开战生成 60 点护盾
- **战地维修包**（120 分/个，每场最多携带 3 个）：战斗中按 `H` 回复 40 HP
- **复合装甲**（永久，5 级）：最大装甲 +25/级
- **反应装甲**（永久，3 级）：受到伤害 -8%/级

> 永久升级价格随等级递增（基础价 × 下一等级）。

## 🎖️ 积分获取

- 击毁侦察车 +40 / 主战坦克 +50 / 重装坦克 +80 / 指挥重坦(Boss) +300（即时入账飘字）
- **连杀奖励**：3 秒内连续击毁，每级连杀额外 +5×连杀数，飘字提示
- 1v1 胜利 +300
- 1v多 清波 +（100 + 50 × 波数），并自动战地维修 15 HP
- 战斗失败 / 撤退时，已获得的击杀与清波积分照样入账

积分、库存、升级与战绩均通过 `localStorage` 持久化（键名 `steel_front_save_v1`），主菜单底部提供「重置存档」入口。

## 🧱 战场要素

- **砖墙**（红棕）：可被炮弹摧毁，血量越低裂纹越多
- **钢墙**（灰）：无法击穿，只能绕行
- **补给掉落**：敌车概率掉落维修 / 弹药 / 护盾充能（1v多模式，25 秒后消失）；Boss 必掉双份
- 每局地图中心对称随机生成，并做出生区连通性校验
- 敌军 AI：追击 / 环绕走位 / 视线检测 / 卡墙自动脱困，新生敌车有 0.9 秒部署保护与 1.5 秒首发延迟

## 🔊 其他

- 音效由 WebAudio 实时合成（射击 / 爆炸 / 拾取 / 购买 / 胜败），无外部音频资源，右上角 🔊 可静音
- 战场 1600×1000 固定视角整屏显示（真·上帝视角观战），自适应窗口缩放
- 桌面端推荐 Chrome / Edge / Safari 最新版；手机 / 平板用浏览器打开在线地址即可（需键鼠的玩法均有对应触控入口）
